## Questions

Can Preview add page numbers to a PDF?

No. Preview has no page-numbering tool; you’d have to add a text box to every page.

Can I start numbering on page 2?

Yes. Choose Skip first page, so the cover stays clean.

Can I number several PDFs as one sequence?

Yes, with Bates numbering, which continues the count across files.
