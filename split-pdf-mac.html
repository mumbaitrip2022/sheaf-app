How it works

Split PDF in three moves.

No app to open, no window to find. It happens where the file already is.

  1. Drag

    Start dragging the file from Finder, Mail, Photos or your desktop.

  2. Pause

    Hold still for a moment. Sheaf’s actions open in a circle around your cursor.

  3. Let go on Split

    Choose single pages, a range like 3–7, or parts under your email size limit.

Three ways to split

  • Every page: one PDF per page, numbered in order.
  • Page range: type pages like 3–7 to pull exactly those into a new file.
  • By size: parts that each fit your email limit (25 MB by default; change it in Settings).

Splitting vs. compressing

If a file is just a little too big, compress it first: one file is easier for the person receiving it. Split when the file is huge even after compressing, like a 300-page scanned archive, or when the receiver only needs some pages.

Removing pages instead

To delete a few pages and keep the rest as one file, use Organize: select the pages and delete them, then save.

Questions

How do I split a PDF into separate pages on a Mac?

In Sheaf, drag the PDF, choose Split › Every page. In Preview, drag each thumbnail from the sidebar to the desktop.

How do I extract certain pages from a PDF on a Mac?

Choose Split › Page range in Sheaf and type the pages you want, like 3–7.

Can I split a PDF by file size?

Yes. Sheaf’s Split › By size makes parts under your email limit, 25 MB by default.
