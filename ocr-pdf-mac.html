Questions

Does Mac have built-in OCR for PDFs?

macOS has Live Text, which lets you select text in images and scans in Preview, but it doesn’t save a searchable PDF. Sheaf uses the same on-device recognition to save one.

Will OCR change how my PDF looks?

No. The text is added invisibly behind each page image, so the page looks the same.

Which languages does OCR support?

Sheaf uses macOS’s text recognition, which reads many languages, including English, major European languages, Chinese, Japanese and Korean, depending on your macOS version.
