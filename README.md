# sheafai.app

Website for Sheaf, the Mac PDF menu bar app.

- Every push to `main` deploys to https://sheafai.app (Cloudflare Pages, see `.github/workflows/deploy.yml`).
- Pages are generated by the scripts in `~/project/compra/website/` (`./build.sh`), then committed here.
- The old address https://mumbaitrip2022.github.io/sheaf-app/ stays up because version 1.0 of the app links to its privacy page.
